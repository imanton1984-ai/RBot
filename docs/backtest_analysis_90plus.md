## 🔍 Ключевые выводы

### 1. 15m — главный генератор сигналов
- **~24 сигнала/день** при p_super ≥ 0.90 (по 181 символу)
- **89% WinRate** — отличное качество
- Удержание до 25 баров × 15мин = 6.25 часов → до 4 цикла/слот/день

### 2. 1h — редкие но точные
- **~1.3 сигнала/день** — слишком мало для 9 слотов!
- **95% WinRate** — превосходное качество
- Удержание до 25 часов → ~1 цикл/слот/день

### 3. 1d — ультра-редкие, но экстремально прибыльные
- **~0.04 сигнала/день** — 1 сигнал за ~25 дней
- **96% WinRate** с TP=10% — крайне высокий expected value

### 4. 5m при 0.90+ НЕ подходит
- **Всего 49% WinRate** даже при максимальном p_super — ненадёжно, не использовать.

### 5. 4h при 0.90+ — практически нет данных
- Только 23 трейда за ~5.5 лет — статистически незначимо.

## 📉 Проблема текущей конфигурации (10%/90% = 15m/1h)

С `max_orders_at_a_time = 10`:
- **15m: 1 слот** → max 4 трейда/день × 8.6% = **3.4% дневной доход**
- **1h: 9 слотов** → всего 1.3 сигнала → **7-8 слотов ПРОСТАИВАЮТ!**
- 1h доход: 1.3 × 13.8% = **1.8% дневной доход**
- **Итого: ~5.2% в день** (trade_size_value=10% depo на трейд)

## ⚠️ КРИТИЧЕСКИЙ БАГ: combined_score ≠ p_super

В `scorer.rs`:
```rust
let dir_factor = 1.0 + dir_confidence; // Range [1.0, 1.5]
let combined_score = p_super * dir_factor;
```

Сейчас `signal_scanner.rs` фильтрует по `combined_score`, а НЕ по `p_super`.
Это значит: сигнал с **p_super=0.60** и **dir_confidence=0.50** даёт `combined_score = 0.90`.

**Решение**: Добавить поле `p_super_min` в конфиг и фильтр `AND p_super >= $X` в SQL-запрос signal_scanner.

## 📋 Итоговые настройки config/order_manager.toml

```toml
# Аллокация слотов — 70% на 15m (основной генератор), 20% на 1h (точные), 10% на 1d (бонус)
tf_15m_pct = 70
tf_1h_pct = 20
tf_1d_pct = 10
tf_1m_pct = 0
tf_5m_pct = 0
tf_4h_pct = 0

# Минимальный P(SUPER) из ML модели — ТОЛЬКО 90+ конфиденс
p_super_min = 0.90

# combined_score min (p_super × dir_factor): 0.90 × 1.0 = 0.90
signal_score_min_15m = 0.90
signal_score_min_1h = 0.90
signal_score_min_1d = 0.90
signal_score_max_15m = 1.9
signal_score_max_1h = 1.9
signal_score_max_1d = 1.9

# Cooldown можно снизить до 6h чтобы чаще использовать тот же символ (опционально)
# symbol_cooldown_hours = 6.0
```
